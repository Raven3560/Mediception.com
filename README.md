# Mediception Science

Official website and digital presence for Mediception Science Pvt Ltd — Clinical Intelligence, Evidence Synthesis, and Biopharma Advisory.

## Features
- Interactive medical intelligence platform presentations (MedCEPs, MediKnowl, KOL Management, Clinical Intel)
- Dynamic service capabilities and clinical evidence showcases
- Case studies and therapeutic expertise filters
- Leadership and team directory with modal profiles
- Responsive design with premium dark/glassmorphic styling

## Running Locally
To launch locally:
```bash
npm install
npm start
```
or open `index.html` directly in any modern browser.
